# Données de démonstration

Le fichier `wallet-demo.wlbak` contient un profil fictif riche destiné aux captures d’écran et aux démonstrations de Wallet Manager.

## Mot de passe

```text
WalletDemo2026!
```

## Importer la sauvegarde

1. Ouvrir Wallet Manager.
2. Aller dans **Réglages → Sauvegarde et restauration**.
3. Choisir **Restaurer une sauvegarde**.
4. Sélectionner `wallet-demo.wlbak`.
5. Saisir le mot de passe ci-dessus.
6. Confirmer le remplacement des données locales de démonstration.

La sauvegarde contient des données fictives en XOF : comptes, opérations sur plusieurs mois, budgets, objectifs, épargne, opérations récurrentes, remboursements, tags et groupes de comptes. Elle ne contient pas de pièce jointe.

> La restauration remplace les données présentes sur l’installation ciblée. Utiliser cette sauvegarde uniquement dans un environnement de démonstration ou après avoir exporté les données à conserver.
